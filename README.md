# KURS.TOP — Repetitorlar va Kurslar Platformasi

Fan va shahar bo'yicha repetitor (o'qituvchi) topish va yangi kurslarni e'lon qilish platformasi.

## Imkoniyatlar
- Fan, shahar va narx bo'yicha qidiruv va filtrlash
- O'qituvchilar va kurslar e'lonlarini joylashtirish
- Foydalanuvchilar kabineti va e'lonlarni boshqarish
- Reyting va sharhlar tizimi
- Ko'p tilli interfeys (O'zbek, Rus, Ingliz)

## O'rnatish va ishga tushirish

1. Virtual muhitni faollashtiring:
```bash
venv\Scripts\activate
```

2. Bog'liqliklarni o'rnating:
```bash
pip install -r requirements.txt
```

3. Loyihani ishga tushiring:
```bash
python app.py
```
yoki `ishga_tushir.bat` faylini ikki marta bosing.

Brauzerda: `http://127.0.0.1:5000`
